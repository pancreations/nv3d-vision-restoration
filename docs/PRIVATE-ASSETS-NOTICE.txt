VISION RESTORATION - PRIVATE PERSONAL ASSETS
DO NOT UPLOAD, PUBLISH, OR ATTACH THIS ARCHIVE TO A PUBLIC RELEASE.
=================================================================

This archive is a private convenience copy for the project owner. Extract it
directly over the public Vision Restoration portable folder. It supplies:

  emitter.fw
    Prepared proprietary NVIDIA emitter firmware. It belongs beside
    VisionRestoration.exe. Public users obtain NVIDIA's EXE download, run the
    included Prepare NVIDIA Firmware.cmd helper, and select that EXE directly.
    The helper extracts firmware automatically without installing NVIDIA's driver.

  models\depth-anything-v2-small-fp16.onnx
  models\depth-anything-v2-base-fp16.onnx
  models\depth-anything-v2-large-fp16.onnx
    Local AI depth models. Base and Large are licensed only for non-commercial
    use. The public release does not redistribute any model weights.

  private-assets\geo11-0.7.11\
    Local upstream Geo11 x86/x64 test files. These are reference/test assets;
    do not copy a generic d3d11.dll into the Vision Restoration app folder.
    Install the correct architecture and game fix in the game's own directory,
    then use the Games tab to connect Vision Restoration's included hook.

Official sources if these assets must be obtained again:

NVIDIA standalone 3D Vision USB controller package 390.41 (direct download)
https://us.download.nvidia.com/Windows/Quadro_Certified/NV3DVisionUSB/390.41/3dvisioncontrollerdriver.exe
This is a USB-only package, not a graphics driver. Do not run its installer.
The Quadro server path does not mean a Quadro GPU is required to extract firmware.
