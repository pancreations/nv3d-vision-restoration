Free & open source · Windows 10 / 11 · Alpha

Vision Restoration

Use your NVIDIA 3D Vision glasses again, on a modern PC. No NVIDIA 3D Vision driver needed, and your graphics driver stays as it is.

Download Getting started What works GitHub

New in 0.3.6: no more black flashing when another program loads the GPU heavily, for example a Cycles render in Blender.

Alpha software. It works very well on a 240 Hz OLED with an RTX 5070 Ti and is still being tested on other setups.

What you can watch in 3D

Side-by-side 3D in any window

Emulators like Dolphin, Blender's stereo viewport, SBS videos. The app captures the window and turns it into real 3D.

Your whole desktop

An AI depth model converts anything on screen from 2D to 3D: videos, 2D games, the desktop itself.

VR games on a monitor

Play SteamVR games in 3D through VRto3D or Wibble Wobble.

Games with 3D fixes

DirectX 11 games with Geo11 community fixes, the same fixes 3D Vision players already know.

Stereo photos

Side-by-side and top/bottom image files, including .jps.

Stream in 2D

Share a steady 2D picture on Discord or OBS while you play in 3D.

Getting started

  1. Download and extract

    Get the latest portable release, extract the whole ZIP to a normal folder, and run Start Vision Restoration.cmd. A printable Quick Start PDF is included.

  2. Give the emitter its firmware

    Original NVIDIA emitter only. Download NVIDIA's 3D Vision USB controller package, but don't install it. Drag it onto Prepare NVIDIA Firmware.cmd. Any graphics card works. RP2040 emitters already include their firmware.

  3. Connect the emitter

    Plug it straight into the PC, start the app, and accept the prompt to set up its USB driver. This happens once per PC.

  4. Calibrate

    Set the monitor to 240 Hz (or 120 Hz), click Match output rate, turn on Software black frame insertion and click Start 3D preview. Close one eye at a time and adjust Phase and Shutter until each eye sees only its own image.

  5. Watch something

    Under Input/Games, choose Capture Window, select a program showing side-by-side 3D, and press Fullscreen 3D (F11). Press Home for the menu.
