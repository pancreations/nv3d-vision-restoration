Open source · Windows 10 / 11

Vision Restoration

Bring NVIDIA 3D Vision glasses back to life on modern Windows PCs. No discontinued 3D Vision driver, no GPU driver downgrade. Just the original emitter, your glasses and a high-refresh display.

Install guide Source code on GitHub

Early development. There is no release yet. Clean full-screen stereo has been confirmed through the glasses on a 4K 240 Hz OLED. Game support is in progress.

What it does

Original emitter, no NVIDIA driver

Talks to the 3D Vision USB IR emitter over WinUSB and uploads its firmware itself. Your current GPU driver stays untouched.

High-refresh output

100, 120, 144 and 240 Hz, SDR and HDR, with black frame insertion for clean eye separation on modern panels.

Live timing controls

Phase, shutter width, phase sweep and eye swap while you watch through the glasses. Saved per display.

Stereo sources

Built-in test scene, stereo image pairs, window capture, Spout and a Blender viewport add-on.

In-game hook

Syncs the glasses to a game's own frames: side-by-side Direct3D 11 games such as Dolphin, and depth-based 3D for Direct3D 12 games.

Diagnostics

Live vblank jitter, present timing and emitter command timing, plus self tests that need no hardware.

What you need

  • Windows 10 or 11, 64-bit
  • NVIDIA 3D Vision or 3D Vision 2 glasses
  • NVIDIA 3D Vision USB IR emitter
  • A display at 100 Hz or higher (240 Hz OLED recommended)
  • Visual Studio 2022 with Desktop development with C++, and CMake 3.24+
  • Your own copy of NVIDIA's 3D Vision USB driver package (for the emitter firmware)

Install and set up the emitter

There is no release build yet, so installing means building from source. Third-party libraries and NVIDIA's firmware are not part of this project. You download them yourself from their official sources.

  1. Build the app

    git clone <repository URL>.git
cd nv3d-vision-restoration
.\tools\Get-Dependencies.ps1
.\build.ps1

    Get-Dependencies.ps1 downloads libusb, Dear ImGui, Spout2 and the ReShade headers from their official releases. The app is built to build\bin\Release\VisionRestoration.exe.

  2. Get the emitter firmware

    The emitter has no permanent firmware. The PC uploads it every time it's plugged in, and that firmware lives inside NVIDIA's driver file nvstusb.sys.

    • Download NVIDIA's 3D Vision USB driver 390.41 (a GeForce package up to 425.31 also works).
    • Don't run the installer. Open the package with 7-Zip and copy nvstusb.sys out of the NV3DVisionUSB.Driver folder.
    .\build\bin\Release\vision_firmware.exe C:\path\to\nvstusb.sys .\build\bin\Release\emitter.fw

  3. Give the emitter the WinUSB driver

    • Plug the emitter straight into the PC. Device Manager lists it as NVIDIA stereo controller (USB\VID_0955&PID_7003) with no driver.
    • Run Zadig, choose Options > List All Devices, select NVIDIA stereo controller (USB ID 0955 7003), pick WinUSB and click Install Driver.
    • After the app uploads the firmware, the emitter restarts as USB ID 0955 0007. If the app can't open it, repeat the Zadig step for that ID and press Refresh USB.

  4. Run and calibrate

    • Run Launch.cmd.
    • Pick your display and refresh rate, click Match output rate, then Start 3D preview. The glasses start shuttering.
    • Adjust Phase and Shutter until each eye sees only its own image. On OLEDs, turn on Software black frame insertion and use Maximize brightness.
