PORTABLE WINDOWS RELEASE

Vision Restoration

Quick Start · Version 0.1.0
Experimental software. Verify each eye independently before normal use. Successful rendering and USB commands do not prove clean optical separation. Stop immediately if the image is uncomfortable or unstable.

The ZIP also includes Vision Restoration README.pdf, generated from the current repository README, with release status and complete setup instructions.

1 · Extract and start

  1. Extract the entire portable ZIP to a normal writable folder. Do not run it from inside the ZIP.
  2. Run Start Vision Restoration.cmd. Windows SmartScreen may warn because this experimental build is unsigned.
  3. Select the intended display, match its current refresh rate, and begin with the built-in eye patterns.

Profiles and diagnostic reports stay inside the extracted folder. Moving the complete folder to another location or PC keeps the application portable.

Included

Main application, window capture, stereo image sources, AI screen-depth helper and runtime, emitter support, x86/x64 Geo11 integration, calibration tools, and RP2040 firmware.

Not included

NVIDIA's proprietary emitter firmware, AI model weights, upstream Geo11 binaries, and game-specific community fixes. Direct download links are included below.

2 · Choose an emitter

Original NVIDIA USB emitter

Requires user-supplied volatile firmware and a one-time WinUSB binding for both USB identities. Continue on the next page.

Vision RP2040 emitter

Copy firmware\VisionEmitter.uf2 to the board while it is in BOOTSEL mode. Reconnect it, start the app, and approve WinUSB setup if requested.

Original emitter setup

Prepare firmware without installing the discontinued graphics stack

3 · Prepare NVIDIA emitter firmware

  1. Download NVIDIA's standalone USB controller package 390.41 directly. This is not a graphics driver; no Quadro GPU is needed for firmware extraction.
  2. Do not run NVIDIA's installer. Run Prepare NVIDIA Firmware.cmd and select the downloaded 3dvisioncontrollerdriver.exe, or drag that EXE onto the helper.
  3. The helper opens the package as an archive, validates the firmware, and writes emitter.fw beside the app. No separate extractor installation is needed. An already extracted nvstusb*.sys also works.
NVIDIA’s firmware is proprietary and is intentionally absent from this release. The generated emitter.fw remains local to the user’s extracted folder.

4 · Allow WinUSB once

The original emitter appears as two devices: 0955:7003 before firmware upload and 0955:0007 afterward. Each identity needs WinUSB once on each PC.

  1. Plug the emitter directly into the PC and start Vision Restoration.
  2. Approve the administrator prompt when the app offers its portable WinUSB setup.
  3. After firmware upload and restart, approve setup for the second identity if requested.

If automatic setup fails, use Zadig, enable Options → List All Devices, and bind only those two NVIDIA device IDs to WinUSB. Do not replace the graphics driver.

5 · First optical check

  1. Choose the display and click Match output rate.
  2. Start the built-in stereo preview at a refresh rate supported by the display and emitter.
  3. Look through one lens at a time. Use eye swap, phase, shutter, and sequence controls until each lens admits its intended image.
  4. Save a profile only after repeating the check across the screen.
Display support varies. LCD, QLED, unusual scanout modes, HDR, multiple displays, and additional GPU generations still need broader optical validation.

Sources and games

Use the input route that matches the content

Stereo images and windows

Open side-by-side or top/bottom stereo images directly, or capture a window that already produces packed stereo. Window capture is the simplest fallback when in-game integration is unsuitable.

Game integration

Vision Restoration can connect an existing Geo11-compatible DirectX 11 fix to the app’s emitter timing and sequential output. Geo11 is not included.

  1. Obtain the correct community fix for the game. Start with 3D Fix Manager, the Helix Mod blog, or the maintained Geo11 releases. Follow that fix’s instructions and confirm it uses force_stereo=2.
  2. Close the game. In Vision Restoration open the left Input/Games tab, select the rendering EXE using Choose game..., and click Prepare game. The display, emitter and timing must be ready first.
  3. Leave Vision Restoration open and launch the game normally. The game retains its original window and input.
  4. Before updating or removing the community fix, close the game and use Disconnect adapter.
Experimental feature: known game crashes. Resident Evil 2 and Metal Gear Solid V remain unresolved and are not supported games in this release. Preparing capture does not fix a crashing renderer. The shared hook supports x86/x64 DX11 and several established Geo11 output modes, but it does not make every legacy fix compatible. Native DX12, DX9/10, Vulkan, native NVIDIA-driver stereo, and arbitrary proxy chains are not covered.

Optional AI screen depth

  1. Download Depth Anything V2 Small, Base, or Large from ONNX Community.
  2. Save each download in the included models folder with a distinct name, such as depth-anything-v2-small-fp16.onnx.
  3. Restart the app and choose AI desktop. Small is fastest; Base and Large are slower and licensed for non-commercial use.

AI depth is unrelated to normal stereo images, window capture, game integration, or emitter control.

Troubleshooting

Useful checks before filing a report

The app does not start

  • Extract the complete ZIP instead of launching from the archive.
  • Keep all DLLs and the runtime folder beside the executable.
  • Check whether antivirus quarantine removed an unsigned executable.

The original emitter is missing or cannot open

  • Confirm emitter.fw exists beside the app.
  • Bind WinUSB separately to 0955:7003 and 0955:0007.
  • Connect directly rather than through a hub, then press Refresh USB.

A game fix is rejected

  • Select the actual game executable and close the game first.
  • Confirm the installed fix is Geo11-compatible and has force_stereo=2.
  • Disconnect Vision Restoration before changing the community fix.
  • Do not manually overwrite files in VisionRestoration.OutputBackup.

Diagnostics

The portable folder keeps application diagnostics under reports. A connected game writes VisionStereo11.log in its own executable directory. Reports can contain hardware, display, timing, and local path information; review them before posting publicly.
