Vision Restoration

Quick Start · Alpha 0.3.6

Vision Restoration runs NVIDIA 3D Vision glasses on a modern PC without NVIDIA's discontinued 3D Vision driver. This guide gets you from download to your first 3D picture. The full README is included as Vision Restoration README.pdf.

Works best on: an OLED monitor at 240 Hz (or 120 Hz). LCD, QLED and Mini-LED screens aren't supported yet, because each eye sees a ghost of the other image.

1 · Extract and start

  1. Extract the whole ZIP to a normal folder. Don't run it from inside the ZIP.
  2. Run Start Vision Restoration.cmd. Windows SmartScreen may warn you because the app isn't signed; choose More info > Run anyway.

Everything, including your settings, stays inside this folder, so you can move it anywhere.

Included

The app, AI depth helper, emitter tools, Geo11 game integration, calibration patterns and RP2040 firmware.

Download separately

NVIDIA's emitter firmware (step 2), the optional AI depth models, and Geo11 game fixes. These belong to other people, so they can't be bundled.

2 · Which emitter do you have?

Original NVIDIA USB emitter

Needs NVIDIA's firmware and a one-time USB driver setup. Continue on the next page.

DIY RP2040 emitter

Hold BOOTSEL, plug in the board and copy firmware\VisionEmitter.uf2 onto it. Reconnect it, start the app, and accept the driver prompt. Then skip to step 5.

Original emitter setup

Two one-time steps

3 · Get the firmware

The emitter forgets its firmware when unplugged, and the app reloads it every time. You need NVIDIA's file once:

  1. Download NVIDIA's 3D Vision USB controller package. It isn't a graphics driver, and any graphics card works even though the link says Quadro.
  2. Don't run it. Drag the downloaded file onto Prepare NVIDIA Firmware.cmd instead.
  3. That's it: emitter.fw now sits beside the app.

4 · Set up the USB driver

  1. Plug the emitter straight into the PC (not a hub) and start the app.
  2. When the app offers to set up the USB driver, accept the administrator prompt.
  3. The emitter restarts once its firmware loads. Accept the prompt a second time if asked.

From now on, plugging the emitter in just works. If automatic setup fails, use Zadig: choose Options → List All Devices and install WinUSB for the NVIDIA devices 0955 7003 and 0955 0007. Never change your graphics driver.

5 · Calibrate your glasses

  1. Set your monitor to 240 Hz (or 120 Hz) in Windows.
  2. Click Match output rate, turn on Software black frame insertion, then Start 3D preview.
  3. Close one eye. Adjust Phase until that eye sees only its own image, then check the other eye. Shutter trades brightness against separation.
  4. If the eyes are reversed, click Swap eye order. Settings save automatically.

Watching in 3D

Pick a source on the Input/Games tab

Side-by-side 3D from any program

  1. Set the program to side-by-side output, for example Dolphin: Graphics > Stereoscopic 3D Mode > Side-by-Side. Use windowed or borderless mode.
  2. Choose Capture Window, select the program, and set Packing: Half SBS if both eyes are squeezed into one picture, Full SBS if each eye is full width, or Top / bottom.
  3. Press Fullscreen 3D (F11). The program keeps your keyboard, mouse and controller. Press Home for the menu.

Your whole desktop in 3D (AI)

  1. Download Depth Anything V2 Small into the models folder. Base and Large look finer but are slower and non-commercial.
  2. Choose Ai 3D Desktop, pick Responsive desktop, and click Start screen 3D. You can keep using your PC underneath.
  3. Ctrl+Alt+PageUp / PageDown changes depth; Ctrl+Alt+F8 stops.

Games with Geo11 3D fixes

  1. Install the game's fix from 3D Fix Manager, Helix Mod or the Geo11 releases.
  2. With the game closed, choose Game Stereo, click Choose game..., select its EXE, and click Prepare game.
  3. Launch the game normally in windowed or borderless mode. 3D starts by itself.
Experimental. Some games still crash (Resident Evil 2, Metal Gear Solid V). Fixes that need NVIDIA's own 3D Vision driver won't work.

VR games on a monitor

With SteamVR running, choose VRto3D (SBS / TAB) or Wibble Wobble. For VRto3D, turn Auto Focus off in its Ctrl+Home > System menu. Both are experimental; see docs/VRTO3D.md and docs/WIBBLE-WOBBLE.md.

Recording or streaming

Captured 3D output flickers on a recording. Tick 2D stream view and share the screen; viewers see a steady 2D picture while you keep seeing 3D.

Troubleshooting

Quick fixes

The app doesn't start

  • Extract the whole ZIP first, and keep every file and folder beside the app.
  • Check whether your antivirus quarantined it (the app isn't signed).

The glasses don't shutter

  • Check that emitter.fw is beside the app (original emitter).
  • Plug the emitter straight into the PC, then click Refresh USB.
  • RP2040 at 240 Hz: turn on Black frame insertion.

Each eye sees some of the other image

  • Fine-tune Phase, then narrow Shutter.
  • On LCD, QLED and Mini-LED screens this can't be fully removed yet.

The picture flashes or loses sync

  • Press Re-lock sync, or Ctrl+Alt+R in fullscreen.
  • If it keeps happening, report it with reports\session.log and reports\miss-events.log. Look through them first: they contain hardware details and folder paths.

A game's fix isn't detected

  • Select the game's real EXE, not its launcher, with the game closed.
  • Make sure it's a Geo11 fix. Click Disconnect adapter before changing it.
