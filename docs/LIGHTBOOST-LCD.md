# Previous LightBoost claim withdrawn

The former button performed model-based ghost subtraction, not backlight strobing.
Its panel response-time claims and fixed custom-timing recipe were not established
by optical measurements. The user reports that this compensation does not work.

Use [LCD / QLED panel experiments](PANEL-EXPERIMENTS.md) for the new optional
neutral-reset/preload paths, the official-emitter test procedure, and cited research.
Only 240 Hz OLED with software black insertion remains proven.
